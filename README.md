# Simplicity

Site institucional multipágina em HTML, CSS e JavaScript, feito como exercício de front-end. É um site fictício, para fins educacionais.

## Páginas

- index.html — apresentação do desenvolvimento front-end, com vídeo incorporado e mapa da localização

- servicos.html — serviços, com galeria de imagens em lightbox

- produtos.html — produtos, com tabela de prazos e valores

- contato.html — formulário de contato com busca de endereço por CEP (API ViaCEP) e envio pelo Formspree

## Detalhes técnicos

- Estilos em css/estilos.css, sem framework de CSS

- Menu responsivo em js/menu.js

- Formulário em js/contato.js, usando jQuery e o plugin jQuery Mask

- Galeria de imagens com a biblioteca Lightbox (pasta lightbox/)

- Layout adaptado a desktop e celular, com media queries

## Como rodar

Abra index.html no navegador. Não há build: o jQuery vem por CDN e o Lightbox está na pasta lightbox/.
